# 默认手绘风格与示例角色

## 0. 先看用户自己的设定

本文件展示作者采用的手绘样式。下面的人物、服装、配色、字体、画幅和位置都是默认参考，可以由用户自定义；“固定”“必须”“不要”等描述，只在用户选择沿用这套示例设定时适用。用户的新设定优先于这里的示例。

可以换成自己的原创人物或小动物，用文字描述或上传参考图；也可以不放人物。先确定本次角色和视觉规则，再在同一组图中保持连续。贝拉是作者个人 IP，不代表每位安装者。

排版可以用单幅、分格、横向步骤或竖向总览。固定七图脚本只实现最后一节描述的那一种布局，其他布局需要另行排版。默认手绘也可以按用户要求改成线描、蜡笔或其他媒介。

## 1. 风格关键词

- 儿童绘本式彩铅线稿 + 淡水彩铺色
- 暖奶油色有纤维感的纸张背景
- 低饱和粉、紫、蓝、嫩绿和鹅黄
- 黑灰色手绘轮廓，边缘略有抖动和铅笔颗粒
- 轻松、亲切、生活化，有真实动作和小表情
- 留白充足，信息少而明确，适合对着图片口播

不要使用：3D 玩具感、塑料高光、纯矢量扁平风、厚重阴影、赛博科技界面、写实摄影、复杂背景、密集信息图。

## 2. 角色锁定

### 贝拉

- 贝拉是 Lidali 的固定人类小人物 IP 和本人替身，可承担观察、提问、动手、解释或旁白。
- 黑色短碎发、侧分刘海、发尾略翘，头顶固定保留一小撮自然翘发；暖肤色圆脸、大而有神的深色眼睛、细黑眉、小鼻子和珊瑚粉腮红。
- 儿童绘本式约 3.5 头身，灵活、有行动力，不画成幼儿或高挑时装人物。
- 默认穿酒红色短款运动背心、炭黑色运动短裤和白灰色运动鞋。
- 青柠绿色手环固定戴在贝拉自己的解剖学右手腕；人物转身、侧身或换到画面另一侧时也不能换腕。
- 动作、表情和位置要随内容变化，不连续复用同一站姿。与阿朱阿兔同场时保持同一种彩铅淡水彩材质和相近头身比例，但贝拉始终是人类角色。
- 角色结构与动作变化以 `assets/bela-character-reference.png` 为准。允许在不改变身份、服装和右手环的前提下改变表情、姿态、朝向与景别。
- 当内容需要个人 IP、真实使用者、旁白或操作衔接时优先让贝拉出现；普通阿朱阿兔纯故事不强制添加。真实录屏、证据截图和真实结果保持原样，不把贝拉硬画进证据本体，可在开场、转场、解释页、边角旁白或结尾露出。

### 阿朱

- 桃粉色小猪女孩，圆头、粉色腮红、小猪鼻。
- 头顶左侧固定一朵紫色五瓣小花。
- 粉色无袖运动上衣，紫色短裤，裤脚有浅紫荷叶边。
- 紫粉色方形智能手表固定戴在阿朱自己的解剖学左手腕；人物转身、侧身或换到画面另一侧时也不能换腕。白色高帮袜和白粉运动鞋。
- 性格外显：好奇、容易惊讶、愿意开口提需求；动作可稍夸张。

### 阿兔

- 白色兔子女孩，长耳朵、粉色耳内、两颗门牙、圆白尾巴。
- 固定粉色发带。
- 蓝色无袖运动裙；蓝色方形智能手表固定戴在阿兔自己的解剖学左手腕，人物转身、侧身或换到画面另一侧时也不能换腕。白蓝运动鞋。
- 性格外显：会思考、能做决定、执行稳；动作自信但不摆专家架子。

角色必须保持儿童绘本比例。阿朱、阿兔不得换成人类或真实动物，三位角色都不得换成幼儿园制服、职业制服或另一套配色。角色结构以 `assets/bela-character-reference.png`、`assets/azhu-character-sheet.png` 与 `assets/atu-character-sheet.png` 为准。

## 3. 字体与文字

- 参考 `assets/handwriting-style.png`：黑色、圆润、细粗略有变化、字距舒展的手写字。
- 中文标题通常放在画面顶部 10%–22% 区域，水平居中；两侧至少保留 7% 安全边距。
- 一幅只放一句短句。推荐 8–20 个汉字；过长时先缩短口播落点，不要把字挤小。
- 英文概念词如 `Agent`、`Skill` 使用同一手写笔触，拼写必须准确。
- 在提示词中用引号提供逐字原文，并写明“不增加其他文字”。生成后必须肉眼逐字检查。

## 4. 场景和构图

- 单幅默认横版 4:3，阿朱和阿兔放在画面中下部，顶部留给一句文字。
- 地面与背景使用浅色水彩块，不要塞满道具。
- 用动作推进故事：指向空地、观察天气、蹲下检查、拿起帐杆、固定地钉、坐下分享成果。
- 小表情承担情绪：张嘴、歪头、擦汗、握拳、眼睛看向关键物体。
- 同一组连环画保持时间、地点、服装、核心道具和左右关系基本连续；只有剧情需要时才换位置。
- 贝拉贯穿多页时，先给每页分配不同动作和位置，例如：角落旁白、抱纸后退、中间蹲查、草地指引、张臂讲解、坐着输入、俯身圈错。变化必须服务本页动作，不为了变化而打断故事连续性。

## 5. Agent 与 Skill 的视觉语法

- Agent：用完整角色或绿色大容器表现“接住目标、做判断、调用能力并推进任务的完整行动系统”。架构图中，Model 和 Skills 可以位于 Agent 容器内部。
- Model：像 Agent 的大脑，负责理解任务、推理和判断下一步；只保留一个大脑图标。不要把 Model 画成 Agent 本身，也不要暗示 Model 独自完成外部动作。
- Skill：用一个具体能力动作或小圆形能力图标表现“Agent 可以调用的一套具体做法”。
- 当前调用的 Skill：黄绿色圆形、柔和光芒、较高对比。
- 其他未调用 Skill：浅灰圆形、低对比、不发光，例如烹饪锅、扳手齿轮、画板画笔。
- 工具：帐杆、地钉、绳子、锤子等留在现实场景。工具不是 Skill。
- 推荐流程：`任务进入 Agent → Model 负责判断 → Agent 选择并调用 Skill → 执行 → 得到结果`。
- 推荐口播：`阿兔整体就是 Agent。她脑子里的 Model 负责想，Agent 再根据这个判断，调用合适的 Skill 把事情做完。`

## 6. 推荐故事骨架

以下七个故事节点按主题取舍，页数服从因果逻辑，不固定为 5–7 幅：

1. 任务：阿朱直接提出一个具体生活任务。
2. 思考：阿兔接住任务，考虑天气、地点、人数和步骤。
3. 变化：现场出现意外或限制。
4. 调用：阿兔用上自己已经会的一门手艺。
5. 执行：两个人按照这门手艺完成关键动作。
6. 结果：具体成果出现，两个人获得真实体验。
7. 揭晓：用最少文字或仅用 `Agent`、`Skill` 图形关系揭示概念。

故事必须先成立，概念解释最后出现。不要一开始先念定义，也不要让每一幅都承担解释任务。

```text

Input images: 按本页角色加载贝拉角色参考、阿朱角色表、阿兔角色表；再加载手写字体参考和最接近本场景的风格参考
Scene/backdrop: {时间、地点、必要背景}
Subject: {阿朱和阿兔正在做的一个具体动作}
Story beat: {这一幅推动了什么}
Style/medium: warm cream textured paper, colored-pencil linework, light watercolor fill, hand-drawn children’s picture-book illustration
Composition/framing: landscape 4:3, characters in the middle/lower area, generous top space for copy
Text (verbatim): “{画面原文}”
Character locks: 本页出现的角色严格遵循各自参考图；贝拉脸、发型、服装、右手环不变，阿朱阿兔服装、花朵、发带、左手表和鞋子不变
Continuity: {与上一幅必须保持的地点、道具和状态}
Constraints: one clear scene, exact text, readable on phone, no extra words, no watermark
Avoid: 3D, vector art, photorealism, sci-fi UI, books/manuals as Skill, extra characters, costume changes
```

```text

Primary request: 用完整阿兔表示 Agent，用一个被点亮的具体能力图标表示 Skill；可在周围加入 2–3 个浅灰未调用能力图标
Text (verbatim): “Agent” and “Skill”
Visual hierarchy: 阿兔整体用绿色手绘轮廓圈出；当前 Skill 用黄绿色圆形和柔光；未调用能力浅灰低对比

Constraints: 阿朱在旁边观察；不加定义长句；不加箭头时依靠位置关系说明；不把工具或说明书画成 Skill
```

## 10. 组合图

已完成的分镜必须像素级拼版，不再交给图片模型重绘。七幅组合图使用：

```bash
scripts/compose-seven-3x4.sh 输出.png 01.png 02.png 03.png 04.png 05.png 06.png 07.png
```

成品为 1536×2048：前六幅两列三行，第七幅底部居中略放大。脚本在目标文件已存在时停止，避免误覆盖。
