# 手绘流程图、对比表与数据图表

先判断信息关系，再选择图的类型；人物和手绘笔触帮助阅读，不能改变逻辑或数据。用户可以指定画幅、配色、角色和排版。默认手绘风格可选彩铅淡水彩、白底钢笔、粗蜡笔、剪纸拼贴或黑白漫画；这些是视觉方向，不是独立模型或保证固定效果的程序预设。

## 选择合适的图

| 内容关系 | 推荐形式 | 先拿到的资料 |
|---|---|---|
| 步骤、分支、循环 | 流程图 | 起点、每步动作、执行者、判断条件、去向、结束条件 |
| 方案、能力或材料的异同 | 对比表/对照图 | 比较对象、统一维度、各项已知事实和未知项 |
| 分类、组成、层级 | 结构图/思维导图 | 父子关系、同层分类、边界，是否有交叉关系 |
| 时间顺序 | 时间线 | 时间点、事件、先后顺序，未知日期不得补成事实 |
| 数值大小、趋势、占比 | 条形图/折线图/比例图 | 原始数据、单位、时间范围、来源、分组口径 |

缺资料时先说明缺口。可以使用明确标注的演示数据，但不能把它写成真实测量结果；没有数值需求时使用定性图，不为了画图编造数字。

## 通用过程

1. 用一段文字或小表列出所有节点、条目和关系，把内容核对清楚。复杂图先给结构草案；用户已经批准的结构和明确限定的 Demo 数量不重复确认。
2. 一图一个目的。选择读者能顺着看的布局，减少交叉线与装饰，字数过多就精简标签或拆图。
3. 写清每条连接的含义，区分“先后、因果、包含、参考、反馈”；不要把并列项画成顺序或因果。
4. 选择角色的实际动作，例如检查、记录、传递或比较；角色不能遮挡关键节点、文字或数字。图示不需要人物时可以不放。
5. 核对图内文字原文，再生成或排版。流程、概念比喻、定性对比图可使用图片模型；涉及精确数值时按下节处理。
6. 出图后逐项对照文字结构和数据源，检查漏项、错字、箭头方向、图例、比例、遮挡与可读性。附上生成提示词或数据来源，区分已生成与已发布。

## 流程图

画明起点、动作节点、判断分支和结束点；分支标注具体条件。箭头到达明确节点，回路返回需要重做的步骤，不能悬空或穿过其他节点。简单任务不强加判断节点，复杂任务不省略影响结论的步骤。

示例关系：提供资料 → 整理设定 → 生成试样 → 用户检查；通过 → 保存角色；需调整 → 返回整理设定。这里是工作方法示意，不是软件自动运行截图。

用户要机器执行或编辑的流程定义时，保留 Mermaid 等结构源文件，再按需要另做插画；PNG 图片本身不可执行。

## 对比表与结构图

比较对象使用相同维度；表格横纵对应清楚，未知信息标“待确认”，不擅自排名。不同起步方式可以并列展示，不暗示其中一种一定更高级。父子层级和交叉关系分别表示，不用装饰连线制造不存在的关系。

示例：照片参考、文字设定、已有角色三种起步方式，对比提供的资料、需要确定的特征与下一步，结果都可以进入角色试画。

## 有真实数字的图表

先核对数据来源、单位、范围、缺失值、类别和加总关系，再选择图形。让 Matplotlib、Vega-Lite、SVG 等可计算方式生成柱高、点位、坐标轴与标签；手绘字体、轮廓和角色仅用于不改变数据含义的装饰。保留数据及可重现的绘图源文件。

不要把已核对的完整数据图交给图片模型重绘。可由图片工具生成独立角色或背景资产，再通过确定性排版合成，避免改动数值、刻度或几何比例。检查条形长度、坐标起点、折线间隔、占比与图例对应；断轴或非零基线需要明确标示。

如果只有图片模型可用，不能声称精确统计图已完成；先交付数据表与绘图方案，说明还缺绘图能力。定性示意图必须标明其用途，不把位置或面积解释为数据大小。

```text
使用 bela-hand-comic，画一张白底手绘流程图。
流程：提供资料 → 整理设定 → 生成试样 → 用户检查。
检查通过就保存角色；需要调整就返回整理设定。
每条箭头落到准确的节点，中文短句清楚，人物只在检查环节参与动作。
先核对逻辑，再生成并逐项检查。
```

```text
使用 bela-hand-comic，画一张手绘对比表，比较照片参考、文字设定、已有角色。
共同维度是“给什么资料”和“重点确定什么”，使用我提供的条目，不添加评分。
三列并排、统一行对齐，用粗蜡笔与少量彩色纸片表现。
中文标签保持准确，图片和人物不能挡住表格内容。
```
