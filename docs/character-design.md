# 第一次设计自己的角色

先告诉助手“它是谁、长什么样、穿什么、给人什么感觉、用来做什么”，就能开始设计。可以上传照片或已有角色图，也可以只有文字想法；不需要先准备完整设计稿。

这些材料发给你正在使用的 AI 助手，或放在它能读取的本地目录，**不用上传到 GitHub**。助手需要具备图片生成和参考图输入能力；只有文字能力时，可以先完成角色设定与提示词。

## 按你手里的材料开始

| 你现在有什么 | 建议提供什么 | 需要说清楚什么 |
|---|---|---|
| 想把自己画成手绘角色 | 一张五官与发型清楚的正面或斜侧照片；在意穿搭时再补一张全身照 | 哪些特征要保留，服装是否照照片，想接近本人还是更卡通 |
| 已经有自己的角色 | 一张清楚、完整的角色图；有正侧背面图也可以一起提供 | 这是人物外形依据；哪些细节不能变，这次要调整什么 |
| 只有脑海中的想法 | 人物或动物类型、外形特点、服装、性格感觉、使用场景 | 哪些已经确定；没想好的部分让助手先提建议 |
| 喜欢某种画风 | 一两张风格参考，或描述“彩铅、淡水彩、粗蜡笔、线描”等 | 参考的是笔触、配色还是比例；不要把风格图里的人物误当成你的角色 |

这里的图片数量只是便于开始的建议，不是固定门槛。照片尽量清楚、光线自然、少遮挡；没有全身照也能开始，但服装和身形要另外确定，不能把助手补出来的部分当作照片里的事实。

## 先提供这五项就够了

| 需要决定什么 | 怎么说比较具体 |
|---|---|
| 角色是谁 | “一位成年短发女生”“一只拟人化橘猫”“我自己的手绘替身” |
| 最容易认出的特点 | “黑色齐耳短发、圆脸、圆框眼镜”；先挑两三个，不必塞满配饰 |
| 常穿什么 | “黄色卫衣、深色短裤、白色鞋子”；没有想法可让助手建议 |
| 给人的感觉 | “亲切、好奇、有行动力”；再补一个动作，比如“喜欢蹲下来观察东西” |
| 用在哪里 | “视频里的旁白角色”“课程里的讲解人物”“生活连环画主角” |

照片决定不出全部设计。即使用同一张照片，写实比例、夸张表情、服装和笔触不同，也会得到不同角色。先确定你最在意什么：像本人、好辨认，还是适合做动作。

可选补充：常用颜色、头身比例、鞋子与配饰、需要保留的左右位置，以及明确不喜欢的元素。不会描述比例也没关系，说“卡通一点，但保留成年人的感觉”就可以。

## 照片、角色图、画风图分别管什么

有多张图时，给每张图标一个用途，例如：

```text
图 1：参考我的脸和发型，衣服不用照搬。
图 2：只参考彩铅线条和纸张颜色，不参考其中的人物。
图 3：参考服装，上衣用黄色，其他按文字设定。
```

如果几张图互相矛盾，选一张作为主要外形依据。明确“长相跟图 1，衣服跟文字，画风跟图 2”，比让助手自行混合更容易核对。

## 复制这段，让助手帮你设计

不会填的项目写“请帮我建议”，保留你已经确定的内容即可。

```text
使用 bela-hand-comic，先帮我设计自己的角色，暂时不画整套故事。

用途：[视频旁白 / 课程讲解 / 生活漫画 / 其他]
角色：[自己 / 原创人物 / 动物；一句话描述]
外形特点：[发型、脸型或其他两三个识别点]
服装与配饰：[常穿什么；需要固定的颜色和位置]
性格感觉：[两三个词，加一个代表动作]
画风：[默认彩铅淡水彩手绘，或填写自己的想法]
参考材料：[每张图片分别参考什么；没有就写“只有文字”]
必须保留：[哪些特征不能改]
不想出现：[不喜欢的元素；没有可不填]
没想好的地方：[请助手建议的部分]

请先整理简短角色设定，只追问会明显改变结果的信息。
方向不清楚时先给文字方案，让我选；方向明确就先做一张全身形象图。
确认后再补侧面、背面和两三个常用动作，并检查还是不是同一个角色。
最后保存角色图和文字设定，供以后画故事时复用。
如果当前不能生成图片，请说明，并先交付文字设定。
```

## 一个填好的例子

```text
使用 bela-hand-comic，帮我设计一个视频旁白角色。

一位成年短发女生，黑色齐耳发、圆脸，戴细圆框眼镜。
穿黄色卫衣、深蓝短裤和白鞋，左手腕戴一条蓝色手环。
感觉亲切、好奇，常见动作是蹲下观察、指着东西解释和坐着做笔记。
采用彩铅淡水彩手绘，暖白纸张，保留成年人的感觉。
我没有参考照片，也不需要长得像某个真人。

先做一张正面全身图，背景简单，不加文字。
脸型、眼镜、衣服配色和左手环是识别点。
先让我确认人物，再补侧面、背面和动作，不急着生成整套漫画。
```

这是需求填写示例，没有为这个例子生成新图。

## 先定人物，再放进故事

1. 助手读材料，整理一份短设定，区分“你已指定”和“助手建议”。方向明确时直接做一张；关键风格没定时，先用文字比较选项，不必一次生成很多候选。
2. 先看一张简单背景的全身形象图。检查像不像你想要的人、比例是否合适、衣服和识别点是否准确。只改最影响结果的部分。
3. 确认主形象后，再按实际需要补侧面、背面和常用动作。各视角分别检查，避免人物转身后换脸、换装或配饰换到另一只手。
4. 保存主参考图与文字设定，作为后续生图依据。需要总览时拼接已经确认的图片，不用模型把多张成图重画一遍。
5. 把确认后的角色放进第一张故事图，检查换动作、景别和场景后是否仍然认得出来，再继续整套制作。

## 最后应该留下什么

- 一张确认后的主形象图；侧面、背面和动作图按需要补充。
- 一份简短文字设定：外形、衣服、颜色、标志物，以及哪些能变、哪些要保持。
- 一条复用要求，例如“后面的图使用这张角色参考，保持脸、发型和衣服，动作与表情按剧情变化”。

这些文件保存在当前角色或主题目录，不必修改 Skill 的安装文件。下次把角色图和设定一起交给助手；不要只说“跟上次一样”，因为新对话未必能读取之前的图片。

参考图能帮助保持一致，但不能保证每一张自动正确。文字、脸、配饰位置和动作仍需要逐张检查。
