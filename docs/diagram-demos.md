# 手绘图示 Demo：贝拉一起讲清楚

2026-09-21，使用本 Skill 整理内容与检查关系，在 Codex 中用内置图片工具生成。这里汇总流程图、对比表、结构图、时间线和生活场景，并保留此前确认的白底试样。图片是方法示意，不是软件操作截图。

## 1. 白底墨线流程图

![贝拉检查角色试样，满意后保存，需要调整则返回设定](images/demo-flowchart.png)

适合讲步骤、判断和返工。先核对“从哪里开始、什么条件进入下一步、哪里需要重做”，再画箭头。贝拉参与检查，让动作服务于流程。

复制给支持图片生成的助手：

```text
使用 bela-hand-comic，参考随包 assets/bela-character-reference.png 中的贝拉 IP。
画一张横版 16:9 白底墨线手绘流程图，标题“把角色设计出来”。
从左到右：给资料 → 定设定 → 试一张 → 满意吗。
“满意”通向“存角色”；“要调整”从下方回到“定设定”。
贝拉在“试一张”旁用放大镜检查样稿，不能挡字或箭头。
黑色线条，少量彩色点缀；只写指定文字，逐条检查方向和中文。
```

## 2. 粗蜡笔对比表

![贝拉指引三种角色设计起步方式的资料对比表](images/demo-comparison.png)

适合并排说明选项。三列使用同一组维度，读者可以横向比较；图中没有评分，也不暗示哪一种更好。贝拉在表外指引，信息保持完整。

```text
使用 bela-hand-comic，沿用随包贝拉角色参考，画横版 16:9 手绘对比表。
标题“三种起步方式”，画风是粗蜡笔，少量蓝、桃色、黄色纸片质感。
三列：照片参考 / 文字设定 / 已有角色。
第一行“给什么”：清楚的照片 / 外形和用途 / 角色参考图。
第二行“先确认”：保留哪些特征 / 外形和穿搭 / 哪些不能改。
贝拉站在表格外指引，气泡写“都可以先试一张”。
列宽一致、行对齐、字要清楚；不加评分，不遮挡内容。
```

## 3. 剪纸拼贴结构图

![剪纸拼贴结构图，将角色设定分为外形、穿搭、感觉](images/demo-collage-structure.png)

适合分类、组成和层级关系。用纸片材质区分三组内容，连线表示组成，不表示步骤。本图列的是角色设定的三个起步维度，详细人物故事还可以另加。

```text
使用 bela-hand-comic，沿用贝拉 IP，画横版 16:9 剪纸拼贴结构图。
标题“角色设定的三个部分”。上层“角色设定”连接三个并列分支：
外形 → 脸型与发型；穿搭 → 衣服与配饰；感觉 → 表情与姿态。
连接线不加箭头，表示组成，不是先后顺序。
使用撕纸边缘、纸片层次和铅笔细节，蓝、黄、酒红、青柠少量配色。
贝拉在侧边动手整理纸片人物，保留角色身份及右腕青柠手环。
检查中文、父子层级和角色配饰。
```

## 4. 黑白漫画时间线

![黑白漫画时间线展示贝拉上午整理想法、下午画草图、晚上检查](images/demo-ink-timeline.png)

适合阶段计划、事件顺序和过程回顾。黑白线描与灰阶衣服保留服装轮廓，青柠手环点色；三次出现是同一位贝拉在不同阶段。图上明确标注只示意顺序，不代表真实耗时或作者实际日程。

```text
使用 bela-hand-comic，画横版 16:9 黑白线描漫画时间线。
贝拉衣服转为灰阶，保持服装款式，只有右腕青柠手环保留颜色。
标题“创作日程示意”。从左到右：
上午 / 整理想法；下午 / 画出草图；晚上 / 检查修改。
三段分别画贝拉记笔记、画画、检查画稿；底部同一条时间线串联。
注明“仅示意顺序，不代表耗时”。不添加具体日期或用时。
检查阶段对应、顺序、中文，以及同一角色的动作变化。
```

## 5. 水彩手账场景图

![贝拉在池塘边的长椅上，将眼前柳树与木桥画入手账](images/demo-watercolor-journal.png)

适合生活观察、个人记录和故事配图。一张只表达一个动作：贝拉把眼前风景画进本子。淡水彩负责环境和气氛，彩铅线条保留人物与画稿细节。

```text
使用 bela-hand-comic，沿用贝拉 IP，画横版 4:3 水彩手账场景图。
贝拉坐在池塘旁的长椅上，把眼前柳树和木桥画进膝上的本子。
保持黑短发、酒红运动背心、炭黑短裤、白灰鞋，右腕青柠手环。
用透明水彩、柔和青绿与淡紫铺环境，人物和本子用清楚的彩铅线条。
画面只写“把路上的灵感画下来”。不要加入真实地点、日期或多余标签。
检查手中画稿与眼前风景的对应，让人物真的在做事。
```

这三张沿用 Skill 已有的选图、角色参考与检查步骤，分别改变材质、信息组织和场景。不需要安装三个新 Skill；出图能力由当前 Agent 接入的图片工具提供。[查看本轮完整生成提示词](more-style-prompts.md)。

## 角色与风格怎么换

这些 Demo 都用了作者的贝拉 IP。可参考 [贝拉人物设定图](../assets/bela-character-reference.png)，保留黑色短发、酒红运动背心、炭黑短裤与青柠配饰等识别点，再按场景安排动作。需要严格保持配饰位置等细节时，逐张对照设定图验收；生成示例不能作为修改原始设定的依据。

使用自己的角色时，把提示词中的“贝拉角色参考”换成你提供的角色图，说明必须保留的外形、服装、配饰和允许改变的部分。没有现成图也可以从文字或照片起步，见 [角色设计指南](character-design.md)。资料发给正在使用的助手，无需公开到 GitHub。

画风、配色、字体、画幅和排版也可以替换。Skill 负责组织要求和检查，不附带图片模型；Claude Code、Codex 等环境都还需要可用的图片工具与参考图输入能力。详见 [安装与环境](../INSTALL.md)。

## 有数据的图怎么办

流程和定性对比可以用图片模型生成。真实数字的柱状图、折线图、占比图，必须提供数据、单位、时间范围与来源，使用可计算的绘图工具绘制几何位置和标签。贝拉可以作为独立插画放在图表旁边，避免重绘或遮挡数据。具体见 [图示与数据规则](../references/diagrams-and-charts.md)。
