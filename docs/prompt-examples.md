# 角色设计提示词参考

选一个接近自己需求的例子，改掉人物、衣服、颜色和用途，就可以发给 AI 助手。方括号里的内容替换成自己的信息；照片或参考图也一起提供。没有装 Skill 时先看 [安装说明](../INSTALL.md)。

这些是可复制的请求示例，没有为每条提示词另行生成样张。实际出图需要当前助手具备图片生成能力；使用照片或参考图时，还要能把图片传给生成工具。

## 1. 把自己的照片变成手绘角色

需要：一张清晰照片。适合做本人替身、视频旁白或个人账号角色。

```text
使用 bela-hand-comic，把我上传的照片设计成一个手绘角色。
保留照片里的脸型、发型和主要五官特征，卡通化，但保留成年人的感觉。
服装改成米白上衣、深绿色长裤和白鞋，整体亲切、自然、有行动力。
采用彩铅线条、淡水彩和暖白纸张，背景简单，不加文字。
先做一张正面全身形象图，让我确认，再考虑其他角度和动作。
照片没有显示的细节按上述设计要求补充，不当作我的真实外貌信息。
```

可替换：服装、画风、卡通程度。特别在意的眼镜、痣或配饰可以单独注明，不必全部都加。

## 2. 没有照片，从零设计一个人物

需要：文字想法即可。下面是完整例子，人物特征可以任意替换。

```text
使用 bela-hand-comic，帮我设计一个原创手绘人物，用作知识视频里的旁白。
一位成年女生，黑色齐耳短发、圆脸、细圆框眼镜。
穿黄色卫衣、深蓝短裤和白鞋，左手腕戴蓝色手环。
性格好奇、亲切，喜欢蹲下来观察东西，不要画成幼儿。
采用彩铅淡水彩手绘，暖白背景，颜色柔和，不加文字。
先做一张正面全身图。
确认后记录脸、发型、眼镜、衣服配色和左手环，作为后续图的固定特征。
```

可替换：年龄感、发型、衣服、配饰和用途。没想好的项目可以删去，并写“请先给我建议”。

## 3. 设计一只自己的小动物

需要：文字描述，可选补充宠物照片。

```text
使用 bela-hand-comic，设计一只会站立和做动作的原创橘猫，作为生活漫画主角。
圆脸、橘色虎斑、奶白嘴周和肚子，保留猫耳、尾巴和爪子的特点。
穿青绿色背带裤，不穿鞋，性格好奇，做事有点冒失但很认真。
采用彩铅淡水彩手绘，简单暖白背景，不加文字或道具。
先做一张正面全身图，重点看轮廓和配色是否容易认出来。
主形象确认后，再安排走路、坐下和拿东西的动作。
```

如果要像自己的宠物，上传照片并写“毛色和花纹以这张图为准”，替换上面的毛色描述。

## 4. 有角色图，只想换成手绘画风

需要：图 1 为角色，可选图 2 为画风参考。只有一张图时删去关于图 2 的句子。

```text
使用 bela-hand-comic，把图 1 的角色改成手绘表现。
图 1 决定人物身份、脸、发型、衣服和配饰位置，保留原来的姿势和构图。
图 2 只参考彩铅笔触、水彩铺色和纸张质感，不使用图 2 里的人物。
两张图发生冲突时，人物特征以图 1 为准，画法参考图 2。
先修改这一张，不扩展新动作，不增加文字或道具。
完成后对照图 1 检查，确认仍然能认出同一个角色。
```

没有画风图时，可以直接写“用粗蜡笔线条、奶油纸张和低饱和蓝绿色”。

## 5. 主形象确定了，补齐视角和动作

需要：已经确认的角色主图和文字设定。还没确认主图时先用前面的提示词。

```text
使用 bela-hand-comic，按我上传的已确认角色图补充参考资料。
保持脸、发型、衣服、颜色和配饰位置一致。
先补一张侧面全身图，确认后再补背面。
然后分别画三个动作：蹲下观察、伸手指引、坐着做笔记。
每张单独生成，简单背景，不加文字；保持接近的角色比例与画面尺度。
每张都对照主图检查，人物转身后配饰不能换到另一只手。
最后把确认过的图片拼成一张角色参考总览，保留各张原图。
```

动作按实际用途替换。只需要正面旁白时，不必为了凑完整而补所有视角。

## 6. 只修改一个不满意的细节

需要：当前图片，以及准确的修改要求。

```text
使用 bela-hand-comic，编辑这张角色图。
只把头发改成齐耳短发，保留原来的发色和刘海方向。
脸、表情、衣服、姿势、背景、配饰和所有其他细节保持不变。
使用当前图作为编辑目标，不重新设计人物。
改好后与原图比较，确认其他地方没有发生明显变化。
如果当前工具不能编辑已有图片，先告诉我，不直接重画整个人物。
```

把“头发”换成具体问题即可，比如眼镜形状、袖子长度或一处文字；想换衣服则明确哪些衣服需要改、配饰是否保留。

## 7. 把确定好的角色放进第一张故事图

需要：角色主图与设定；先试一张，方便看角色是否能适应场景。

```text
使用 bela-hand-comic，用已确认的角色做一张生活故事图。
人物的脸、发型、衣服和配饰以附件及文字设定为准。
场景是周末的书桌旁，她坐着翻开笔记本，准备记录今天的一件小事。
横版 4:3，人物在画面右侧，上方留出一句话的位置，背景道具简洁。
画面文字逐字写：“今天先做好一件小事”。
沿用角色图的手绘笔触和配色，不额外添加标题或标签。
完成后检查人物一致性、手部动作和文字，再决定是否继续做后面的故事。
```

想改排版，可以替换为“竖版 3:4，文字在上，人物在下”；场景与文字应一起改，避免画面和句子表达不同的事情。

## 不知道如何描述时

可以先发这句，让助手帮你把想法变具体：

```text
使用 bela-hand-comic，我想设计自己的手绘角色，但还没想好细节。
用途是：[填写用途]。我已经确定的是：[填写已有想法]。
请先用文字给我两个有明显区别的方向，分别描述轮廓、服装、配色和性格感觉。
说明它们各自适合什么表现，再让我选一个继续，不要立即批量生图。
```

主图确认后，把角色图和简短设定一起保留。后续换对话时重新提供它们；单靠“和上次一样”不能确保新对话拿得到原参考。[查看资料准备与确认步骤](character-design.md)
